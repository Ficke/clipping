# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to aficke@gmail.com. Include
the affected component, reproduction steps, and potential impact when possible.
Do not include active credentials or personal data in a public issue.

I will acknowledge a report as soon as practical and coordinate disclosure and
remediation with the reporter.

## Supported version

Security fixes are applied to the current `main` branch. Older commits and
deployments are not supported.
